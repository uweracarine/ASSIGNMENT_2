# Discover Kigali - Tourism Website

## Project Description

This is a website about things to do and places to eat in Kigali, Rwanda. I made this for my HTML and CSS assignment.

## HTML Pages

1. **index.html** - Home page with links to all other pages and a Google Map
2. **activities.html** - Things to do in Kigali with a list, table, video, and form
3. **restaurants.html** - Places to eat with a list, table, audio, and form
4. **culture.html** - Cultural experiences with embedded video and form
5. **nightlife.html** - Nightlife venues with a list, table, and form
